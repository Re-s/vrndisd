# 基本连接示例

最简单的 VRNDIS 服务器-客户端连接，建立虚拟网卡隧道。

## 架构

```
[客户端] <-- TAP 设备 --> [vrndis-go 服务器] <-- TAP 设备 --> [远程系统]
```

## 配置

### 服务器端 (127.0.0.1:7777)
- 网络: 10.77.0.0/24
- 网关: 10.77.0.1
- MAC: 02:00:00:00:00:00

### 客户端 (本机)
- 自动分配 IP: 10.77.0.100/24
- 网关: 10.77.0.1
- MAC: 02:00:00:00:00:01

## 使用步骤

1. 启动服务器：
   ```bash
   ./build/bin/amd64/vrndisd server --listen 0.0.0.0:7777 --network 10.77.0.0/24 --gateway 10.77.0.1
   ```

2. 启动客户端：
   ```bash
   ./build/bin/amd64/vrndisd client --server 127.0.0.1:7777 --name my-client
   ```

3. 测试连接：
   ```bash
   # 在客户端测试
   ping -c 4 10.77.0.1  # 连接网关
   ping -c 4 10.77.0.2  # 连接其他客户端
   ```

## 预期输出

```
客户端: 已连接 127.0.0.1:7777，本机地址 10.77.0.100/24 网关 10.77.0.1
服务器: 客户端接入 127.0.0.1:12345 -> 分配 10.77.0.100 (02:00:00:00:00:01)
```

## 故障排查

- 确保防火墙允许 TCP 7777 端口
- 检查 TAP 设备请求权限
- 验证网络配置冲突
